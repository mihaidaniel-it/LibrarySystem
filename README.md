# Java Mini Project: Library System

A simple Java project created for practice. Allows functions with books.

---

## 📌 Description

This project is a small Java application developed to practice and strengthen programming skills.  
The main features of the project include:

- OOP: was used classes and methods for work with objects
- Project structure: all classes have his package which identify his functionality

---

## 🚀 How to Run

To run the project locally:

```
git clone https://github.com/mihaidaniel-it/LibrarySystem.git

cd LibrarySystem

javac LibrarySystem.java

java LibrarySystem
```
